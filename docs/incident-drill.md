## Scenario

The SEC re-publishes `2022q3.zip`; in `num.txt` the column `value` is now called `amount`. Without a contract the loader would land a quarter without amounts and every KPI of that quarter would silently be empty.

## What made it work

- The column contract (`REQUIRED` in `ingestion/sec_fsds.py`) is checked for every table of the zip before any partition is written, so a broken file cannot leave a half-replaced quarter.
- The manifest records the failed file with its checksum; the file is not marked as loaded, so the next run retries it.
- Satellites are insert-only and incremental, so the rerun of one quarter adds nothing when the content is unchanged; the marts come out identical.
- In production the failed `pl_load_sec_fsds` sends the failure e-mail; the reports keep showing the last good load because `pl_transform` does not run after a failed load.
